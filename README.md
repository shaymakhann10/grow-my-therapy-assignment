# GrowMyTherapy Internship Assignment

## Project Overview
This repository features a precise structural clone of the Conejo Valley Counseling homepage, completely themed and customized for an imaginary therapist profile (Dr. Maya Reynolds, PsyD based in Santa Monica, California).

## Features Implemented
- **UI Structure Replication:** Maintained layout logic, responsiveness, and grid architectures of the reference website.
- **Custom Aesthetic Theme:** Implemented a calming, high-contrast Sage Green and Muted Terracotta palette suitable for stress recovery.
- **Copywriting & SEO:** Localized for Santa Monica keyword authority targeting high-achieving professional burnout.
- **Custom Section:** Designed and integrated a functional "Our Office" environmental spotlight module.
